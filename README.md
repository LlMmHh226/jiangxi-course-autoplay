# 江西课程连播与播放控制

一份适用于江西省补贴性线上职业技能培训管理平台的视频课程的篡改猴用户脚本。它整合课程连播、十分钟强制刷新、后台播放和倍速控制。

## 功能

- 视频自然结束后，根据课程目录中唯一匹配的下一节链接安全接续；先确认旧页面关闭，再打开下一节。
- 每十分钟强制刷新当前课程页，刷新或短暂加载失败时自动恢复；自动连播暂停不会停止刷新计时。
- 切换到其他软件后，尝试恢复平台自动暂停的视频；仅在实际播放进度前进后记录后台播放确认。
- 提供跟随播放器、1、1.25、1.5 和 2 倍速选项，并记住所选速度。（倍速可能会有bug）
- 优先使用平台原生倍速。课程如果会拒绝加速进度，脚本会退回正常速度；同一课程后续没有原生倍速选项的单元会保持正常速度，避免反复回退。
- 在页面上显示刷新倒计时和运行记录。

## 安装

1. 在篡改猴中新建脚本，粘贴 `outputs/jiangxi-autoplay.user.js` 的全部内容并保存。
2. 打开匹配课程页面，确认出现“连播、刷新与倍速 · 4.7”面板。
3. 如果正在使用其它倍速扩展，请先停用它，避免同时修改视频速度。

遇到验证码、人脸验证或平台提示时，需要本人处理。脚本不代答验证、不伪造学习进度，也不会把播放位置强行跳到服务器退回的位置。受平台限制的未完成课程可能只能保持正常速度；倍速下拉框会显示实际速度和限制状态。

版本 4.7 已通过语法检查和 81 项浏览器模拟检查，并在真实课程页面中核对了定时刷新后的续播、自然切课和原生二倍速播放。
